# Cloth Separator For VRChat (Unity Tool)

## Description

- - Hi, this and a tool that will allow you to break down a complete Outfit, into individual objects by mesh.
    Assuming your outfit is a hat, top, and pants, this will separate them into hat objects, top objects, and pants objects. Each separate object will remain limited to the bones that affect its mesh.
    It's the perfect tool for separating specific parts of an outfit or creating a menu for separating parts using modules.

### Instalation

- to install it is simple you open your `Unity project` then normally with the file that you downloaded you must have a file named `HjuiihuTools.unitypackage` you drag it into your unity project in the `Assets` folder.
   once done you must have this which appears or otherwise in your `assets` tab then `Import Package` & `Custom Package` by selecting the `HjuiihuTools.unitypackage` file.

## How To Use

### First method 

There are two ways to use this tool.

- The first method is to Right-click on the garment in the Hierarchy and select Hjuiihu Tools - Seperator Cloth
- picture 

![alt text](https://image.noelshack.com/fichiers/2025/03/6/1737199963-capture1.jpg)
![alt text](https://image.noelshack.com/fichiers/2025/03/6/1737199984-capture4.jpg)

### Second method 

- The second method is to select Hjuiihu Tools - Seperator Cloth from the top menu, then put the garment in the Original Clothing section of the menu and click Seperate Cloth to separate it.
